# 打印助手 隐私政策

**生效日期：** 2026-11-20  
**开发者：** BD1BWG  
**联系方式：** support@fire-tnt.cn

本应用（打印助手 / PrintBox）用于在用户自有的绿联 NAS 上直接打印文档与扫描文档。

## 一、处理的数据

1. 用户选择打印的文档与图片（PDF、JPEG、PNG）；
2. 扫描仪扫描生成的图片；
3. 打印机与扫描仪的地址、打印参数等设置；
4. 打印任务记录（文件名、时间、份数、状态）。

## 二、数据存储

- 全部数据**仅存储在用户自有的 NAS 本地**，不会上传至开发者或任何第三方服务器；
- 打印任务记录保存在应用数据目录的 SQLite 数据库中；
- 扫描与上传的文件保存在用户本地的应用数据目录。

## 三、网络访问

- 应用仅在用户局域网内访问打印机（IPP 631 / RAW 9100）与扫描仪（eSCL）；
- 不进行任何外部数据上报，不包含统计 SDK 与广告 SDK。

## 四、数据共享

本应用**不出售、不共享**用户数据。

## 五、用户权利

用户可随时删除应用数据与打印记录，卸载应用后数据目录可由用户自行清理。

## 六、联系我们

如对本政策有疑问，请联系：support@fire-tnt.cn。
